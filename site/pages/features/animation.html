Animation included

Every change animates — by key, and the way you direct it

Marks in datars carry the key of their data row. When anything changes — a story step, a filter, new data, an edit — the engine pairs old marks with new ones by key and plans the move: shapes morph across chart types, a bar shatters into its units, a country flies off the map into its bar, numbers count, the camera flies. You describe states; motion rules say how they move. The playground below runs the real engine: change the rule, replay, scrub, slow it down.

Why it moves well

Identity, plans and time, kept apart

Most chart libraries tween whatever pixels changed. datars knows what each mark is, plans the whole move once, and evaluates it as a pure function of time — which is what makes every trick on this page possible.

Keys carry identity

A mark is keyed by its data row, so a bar, a slice, a map region and a dot of the same row are the same element in different shapes. Pairing by key, a parent splitting into its units by key path — no transition code, ever.

Plans are functions of t

A change builds a plan — who becomes whom, each element's window, easing, route and morph — once. A frame is plan.at(t): the scrub above seeks it, scroll can drive it, a second change retargets from the current frame with its velocity.

Deterministic everywhere

The same plan gives the same frames on the web, iOS, Android and desktop, in an MP4 from datars video, a filmstrip from datars film, and the 64-frame goldens datars test checks for flashes, pops and NaN.

Your scene → the standard library

A rose you drew becomes std's bars and pie

The petals are plain geom.arc shapes in a scene of your own — no recipe, no chart type. The bars and the pie come from @datars/std. Because each petal, bar and slice is keyed by its party, one rule pairs them across all three.

repeat("votes", shape(geom.arc({ cx, cy, r0, r1: e(petal), a0, a1 }),
  { key: e("d.party"), fill: e("key.color(d.party)"), semantics: { role: "datum" } })),
// … then plot({ children: [bar()] }) and pie(), keyed by the same rows
motion: motion({ select: { role: "datum" }, matcher: "by-key", duration: 1.3,
  choreo: choreo.stagger("value", 0.35) }),

Units split and merge

Seats into bars into squares

Seats are keyed (party, seat i), so the engine knows a bar is their parent: they gather into it, and it breaks into squares — its rectangle partitioned into cells that fly to their places. No rule asks for it.

motion({ select: { role: "datum" }, duration: 1.6,
  choreo: choreo.stagger("left", 0.45) })

Choreography

Together, staggered, in a wave, rippling

One duration, spread over the elements: by data order, position, value or a seeded shuffle; a wave across the scene at any angle; a ripple from a point; or exits, moves and entries in phases.

Axes rescale

Gridlines travel with their values

Ticks and gridlines are keyed by the value they mark, so a rescale moves them with the data; the line keeps its points as vertices, and points cut off by a zoom slide out through the edge.

{{alt:motion-rescale}}
Numbers count

Text that is a number ticks

A text with number: { value, format } counts through the values in between, formatted every frame in the document's locale, while the bars grow.

text("", [0, y], { number: { value: e("people"), format: ".1f" } })

Routes

Eight paths from here to there

Straight, arc, elbow, spiral, explode, hop, drift and drop — detours that are exactly zero at both ends, so every settled state is exact.

{{alt:sdk-motion-routes}}
Path morphs

A star into a bar, three ways

When a mark changes kind its outline must become another. morph: "disc" travels through an area-matched disc that never folds (the default), "resample" goes point by point along equal-length outlines, "crossfade" swaps them.

{{alt:motion-morphs}}
Clocks · ambient motion

Planets that go round by themselves

A signal with a rate — signal.clock(1) — counts up while the settled chart reads it. It pauses for transitions (a morph never jumps), off screen and for reduced motion; renders see its default.

{{alt:motion-clock}}
Camera flights

The camera flies, the reader keeps their place

A view's camera is interpolated too — along the van Wijk path, which zooms out to travel and back in to land. A step only says which keys to fit:

map({ …, camera: { fit: { keys: "=focus" }, padding: 16 } }),
step("asia", { set: { focus: ["IND", "CHN", "PAK", "BGD", "IDN"] } }),

Scroll scrubs the plan

Your scroll is the clock

With <datars-view scrub> the page's scroll position is the position in the story: every frame of every transition, forwards and backwards, exactly — because a frame is a function of t, not of how long ago something started.

motion(
  { duration: 1.6, easing: "cubic-in-out" },
  { when: { from: "bars", to: "map" }, select: { role: "datum" }, route: route.arc(0.35), choreo: choreo.stagger("value", 0.5) },
  { when: { from: "map", to: "spiral" }, select: { role: "datum" }, route: route.spiral(0.5), choreo: choreo.ripple(0.55) },
  { when: { from: "spiral", to: "grid" }, select: { role: "datum" }, choreo: choreo.wave(0.6, 0) },
)

Reduced motion

Polite by default

A reader who asks their system for less motion gets every transition as a short crossfade — on the web, iOS and Android — with autoplay and clocks paused. Nothing to author: it's the engine's, for every document. The same chart, the same steps, side by side:

Stories steer themselves

A story is a list of states

A step sets signals; marks read them; the motion comes with it. The same program is stepped with buttons and arrow keys, scrubbed by scroll, triggered by scroll steps, or played on a timer.

Live data animates too

A live source re-requests on schedule; each snapshot animates into place — keyed bars move to their new ranks on election night.

Edits animate

In datars dev, saving the document morphs the chart from what's on screen to the new version, so you see what changed.

Interruptions retarget

A click mid-flight plans onward from the frame on screen, carrying each element's velocity into springs — try it in the playground: pick a layout while one is still moving.
